# 3. Не включать Git и GitHub в runtime-архитектуру ML-системы

Date: 2026-11-03

## Status

Accepted

## Context

Git и GitHub используются для истории изменений исходного кода, конфигураций и выбранных отчётных артефактов. Обработка CSV, выполнение EDA и будущий inference-сценарий запускаются локально и не требуют обращения к GitHub.

## Decision

Показывать Git и GitHub как внешние средства разработки и версионного контроля, а не как внутренний контейнер или runtime-зависимость приложения.

## Consequences

- контейнерная диаграмма отражает только компоненты, участвующие в локальной обработке;
- наличие удалённого репозитория не считается механизмом проверки качества данных;
- получение или отправка изменений в GitHub выполняется как отдельная операция сопровождения проекта.
