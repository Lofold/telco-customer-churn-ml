# 4. Исключать утечку целевой переменной и обучать преобразования только на Train

Date: 2026-11-03

## Status

Accepted

## Context

Будущий конвейер должен оценивать качество модели без утечки целевой переменной и без подгонки преобразователей на валидационных, тестовых или прогнозируемых данных. В incoming-пакете фактическая метка может быть доступна только после формирования прогноза.

## Decision

Исключать `Churn` и `customerID` из матрицы предикторов. `customerID` сохранять отдельно для трассировки. Обучаемые преобразования (импутация, кодирование, масштабирование и другие fit-операции) подгонять только на Train; те же сохранённые преобразования применять к Validation, Test и incoming-пакетам без повторного обучения. Test использовать для итоговой независимой оценки после выбора модели.

## Consequences

- `Churn` не участвует в построении прогноза;
- `customerID` остаётся доступен для сопоставления результата с записью;
- параметры преобразований не зависят от Validation, Test и будущих incoming-пакетов;
- данное решение является целевым архитектурным правилом: реализация и проверка полного ML pipeline ещё должны быть выполнены.
