# 2. Хранить исходные и производные данные раздельно

Date: 2026-11-03

## Status

Accepted

## Context

Для воспроизводимости экспериментов необходимо сохранять исходный CSV в исходном состоянии и отделять его от выборок, входящих пакетов и результатов обработки. Исходный набор не содержит надёжных временных меток снимков клиентов.

## Decision

Считать `data/raw/` неизменяемым источником. Начальную выборку, имитируемые incoming-пакеты и будущие обработанные наборы хранить отдельно. Для контроля целостности использовать SHA-256 и манифест данных. Разбиение `initial_60` / `incoming` не трактовать как Train / Validation / Test.

## Consequences

- исходный файл можно проверять по хешу после выполнения сценариев;
- производные наборы можно пересоздавать без перезаписи источника;
- имитация поступления пакетов не должна интерпретироваться как реальная временная последовательность;
- Train / Validation / Test формируется отдельным этапом разработки модели.
